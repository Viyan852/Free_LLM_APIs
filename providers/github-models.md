# GitHub Models

A GitHub-hosted model playground and inference API that let developers call models with a GitHub personal access token.

> [!WARNING]
> **GitHub Models has been retired.** GitHub's documentation states that as of **July 30, 2026** the playground, model catalogue, inference API, and bring-your-own-key support are no longer available to any customer. This page is kept for historical reference and to point readers at migration options; it intentionally contains no working code examples.

- Documentation: <https://docs.github.com/github-models>

## Why this page still exists

Plenty of tutorials and blog posts still reference GitHub Models. Keeping a page that records the retirement saves readers from debugging an endpoint that is gone.
